AMPScript Logic

is the AMPscript logic that retrieves and processes the traveler's data from the data extension. This script initializes variables, retrieves attribute values, and handles cases where attributes might be empty. The processed data is then used to dynamically populate the email content with personalized statistics for the traveler.


%%[ /* Initialize variables for the traveler's statistics */

*/ VAR @guestName, @topDestination, @loyaltyPoints,
@nightsStayed, @topBadge

/* Retrieve attribute values from the data extension */
SET @guestName = AttributeValue("FirstName")
SET @topDestination = AttributeValue("TopDestination")
SET @loyaltyPoints = AttributeValue("LoyaltyPoints")
SET @nightsStayed = AttributeValue("NightsStayed")
SET @topBadge = AttributeValue("TopBadge")


/* Handle cases where attributes might be empty */
IF EMPTY(@guestName) THEN SET @guestName = "" ENDIF
IF EMPTY(@topDestination) THEN SET @topDestination = "" ENDIF
IF EMPTY(@loyaltyPoints) THEN SET @loyaltyPoints = "" ENDIF
IF EMPTY(@nightsStayed) THEN SET @nightsStayed = "" ENDIF
IF EMPTY(@topBadge) THEN SET @topBadge = "" ENDIF
]%%
